# Movie Catalog App

A full-stack web application built with **ASP.NET Core**, **React**, and **SQLite**.  
It allows users to search for movies via the TMDB API, view details, and save favorites.

## Tech Stack
- **Frontend:** React + Material UI  
- **Backend:** ASP.NET Core Web API  
- **Database:** SQLite with Entity Framework Core  
- **API:** The Movie Database (TMDB)

## Features
- Search movies by title  
- View posters, descriptions, and ratings  
- Watch trailers  
- Save favorite movies locally  

## Getting Started
1. Clone the repository  
2. Run `dotnet run` in `/server`  
3. Run `npm start` in `/client`
